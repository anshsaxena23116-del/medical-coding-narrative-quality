# Medical Coding and Narrative Quality — Training Deliverable

## Contents
- `Medical_Coding_Narrative_Quality_Report.docx` — formatted report with coding table, chronological narratives, and follow-up priorities.
- `medical_coding_table.csv` — normalized product/event terms and key case fields.
- `chronological_case_narratives.txt` — copyable narratives.

## Method
- Product is normalized as **Velunex**; active ingredient, strength, dose, route, and indication remain not reported.
- Candidate event terms: Nausea, Loss of consciousness, Rash (reported as mild rash), and Appendicitis.
- These are candidate plain-language mappings only. Verify terms against your organization's licensed/current MedDRA version before formal coding; no MedDRA codes are claimed.
- Narratives use only supplied facts. Relative onset is retained as reported; no calendar dates or causality conclusions are invented.
- PV-102 and PV-104 have hospital admission/hospitalisation noted in the source and should be prioritized for seriousness-detail verification.
